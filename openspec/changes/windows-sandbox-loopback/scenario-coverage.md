# Scenario coverage

Scenario inventory: `rg '^#### Scenario:' openspec/changes/windows-sandbox-loopback/` (21 scenarios in `auth`, `server-transport`, `sandbox-runner-bash` and `terminal`). `server/test/confinedLoopbackMxc.test.ts` runs against the real `wxc-exec.exe` 1.1.0 and MXC's in-process SDK where `MXC_EXEC` is set and a Python is on the search path; it ran on Windows 11 24H2 (10.0.26100.9711, tier `base-container`, Python 3.15.2) for this change, 7 of 7. No CI job has MXC tier 1 on Windows.
