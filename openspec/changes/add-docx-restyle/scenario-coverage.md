# Scenario coverage — add-docx-restyle

Capabilities: `docx-templates` (1 requirement, 10 scenarios), `agent` (1 requirement, 2 scenarios).

The document under test is `server/test/fixtures/docx-drifted.docx` (an English Word's ids, its own
Arial styles, theme and Roman heading numbering, hand-set fonts, sizes and colours in every story);
the template is `docx-template.dotx` (a French Word's ids, numbered "1. / 1.1."). Both are written
by `server/test/fixtures/make-docx-template.mjs`.

## docx-templates

| Scenario | Coverage | Evidence |
| --- | --- | --- |
| DocumentTakesTheTemplatesStyles | covered | `server/test/docxRestyle.test.ts` — "DocumentTakesTheTemplatesStyles: headings on the template's ids, its style sheet and theme". Asserts the headings reference `Titre1`/`Titre2` and no `Heading1`/`Heading2` is left, the template's definition of heading 1 is in `styles.xml` (only its numbering id renumbered), the document's own definitions and `Times New Roman` defaults are gone, and `theme1.xml` is byte-identical to the template's. |
| HandSetFontsSizesAndColoursAreRemoved | covered | `server/test/docxRestyle.test.ts` — "HandSetFontsSizesAndColoursAreRemoved: in the body, a heading, a list, a table, a text box, a footnote and the header". Asserts no `w:rFonts`/`w:sz`/`w:szCs`/`w:color` on the pasted run, the heading, a list item, a table cell, a text box, a run after a section break, the paragraph mark, the footnote and the header; the comment keeps its font and the equation its math font; the counts are 17 runs, 14 fonts, 6 sizes, 3 colours. |
| OtherFormattingIsKept | covered | `server/test/docxRestyle.test.ts` — "OtherFormattingIsKept: emphasis, superscript, highlight, spacing and indentation stay". Asserts, untracked, that the bold, italic, superscript and highlighted runs keep exactly `<w:b/>`, `<w:i/>`, the `vertAlign` and the `highlight`, and the paragraph keeps its hand-set `w:spacing` and `w:ind`. |
| HeadingNumberingFollowsTheTemplateAndListsKeepTheirs | covered | `server/test/docxRestyle.test.ts` — "HeadingNumberingFollowsTheTemplateAndListsKeepTheirs". Follows heading 1's `numId` to its definition in the document's `numbering.xml` and asserts the template's `%1.` / `%1.%2.`, on an id past the document's; the document's Roman definition no longer links a style; the document's own list keeps `numId` 2 → abstract 1 (`lowerLetter`) and its paragraphs still reference it. The LibreOffice render in the wire test shows the bookmarks as "1. Introduction … 2. Conclusion". |
| PageSetupAndHeadersOnlyOnRequest | covered | `server/test/docxRestyle.test.ts` — "PageSetupAndHeadersOnlyOnRequest: margins and headers from the template, orientation kept". Without `include`: the document's three `pgMar` and its header are untouched. With `include: ["page", "headers"]`: every section has the template's margins, the portrait sections its portrait size and the landscape section the landscape size with `w:orient`; each section's old page setup is a `w:sectPrChange` by pi-outpost, last in the section; every section references the template's header and footer, whose parts are byte-identical to the template's; the old header and its content type are gone; the report says both. |
| AStyleTheTemplateLacksIsKept | covered | `server/test/docxRestyle.test.ts` — "AStyleTheTemplateLacksIsKept: carried with its definition, named in the answer". Asserts the paragraph keeps `Encadre`, its definition is in the new `styles.xml` based on the template's `Normal`, `missingStyles` is exactly `[{ name: "Boxed text", uses: 1 }]`, and the report names it. |
| TheTextIsUnchanged | covered | `server/test/docxRestyle.test.ts` — "TheTextIsUnchanged: every text node of every story is the original's, and a difference stops the write". For the default, untracked and `include` runs, asserts the text nodes of the body, the footnotes and the comments equal the original's in order; and calls the check the tool runs before writing, `assertTextUnchanged`, to show that formatting alone passes and one changed character is refused with "nothing was written". |
| RemovalsAreTrackedByDefault | covered | `server/test/docxRestyle.test.ts` — "RemovalsAreTrackedByDefault: each run keeps its old properties in a w:rPrChange by pi-outpost". Asserts the pasted run's `w:rPr` holds exactly a `w:rPrChange` by pi-outpost, dated, containing its old font, size and colour; the bold run keeps `<w:b/>` with the old properties recorded; the 17 revision ids are unique across the body, the footnotes and the header; the report says the style definitions are not tracked; no `sectPrChange` without `include`. |
| PendingRevisionsAreRefused | covered | `server/test/docxRestyle.test.ts` — "PendingRevisionsAreRefused: an insertion nobody accepted stops the restyle" asserts the refusal and its reason on `docx-drifted-tracked.docx`; "a refusal names the file and writes nothing" asserts, through the tool, the message names the file and no output exists. |
| TheOriginalIsKeptUnlessOverwriteIsAsked | covered | `server/test/docxRestyle.test.ts` — "TheOriginalIsKeptUnlessOverwriteIsAsked: the result goes to output_path, the original stays". Through `docx_restyle`: the original's bytes are unchanged after a write to `output_path`; refusals without `output_path` and onto an existing file leave it unchanged; `overwrite: true` replaces it. `server/test/wordToolsWire.test.mjs` — "the agent brings an old document into the template and renders it" asserts the same over a real server. |
