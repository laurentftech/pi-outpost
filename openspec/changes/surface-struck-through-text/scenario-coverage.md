# Scenario coverage — surface-struck-through-text

Every `#### Scenario:` declared by this change's delta specs, matched to the assertion that would
fail if the contract broke. 24 scenarios: 14 in `docx-documents`, 10 in `pdf-documents`.

Enumerated with `rg '^#### Scenario:' openspec/changes/surface-struck-through-text/specs/`.

Both readers are driven through their public entry point — `extractDocx` and `extractPdf` — against
generated fixtures whose markup and coordinates are known, so an assertion about the returned
markdown is an assertion about what a caller receives. The unit-level tests below the entry point
exist where a case cannot be produced by any fixture: a rejecting operator list, a budget that
expires mid-read.

The same behaviour was then checked against real Word output — a `.docx` and the PDF printed from
it — in `verification.md`. Those checks are not a substitute for any row here; they are what
confirms the fixtures describe the real producer.

## `pdf-documents`

| Scenario | Coverage | Assertion evidence |
| --- | --- | --- |
| StruckTextIsAnnouncedBeforeTheContent | covered | `server/test/pdf.test.ts` — "StruckTextIsAnnouncedBeforeTheContent: the warning leads, it does not trail" asserts the markdown *starts* with the notice and that `## Page 1` comes after it. |
| NothingStruckAnnouncesNothing | covered | `server/test/pdf.test.ts` — "NothingStruckAnnouncesNothing: a page that draws no strike carries no notice" asserts `doesNotMatch(/crosses out/)` on the decoy page, which draws an underline, a page rule and a ruled table. |
| WordStrikethroughIsMarked | covered | `server/test/pdf.test.ts` — "WordStrikethroughIsMarked: the struck run comes back as a span" asserts `Le prix est de ~~cent euros~~ deux cents euros.` against a fixture whose strike rectangle is placed at the height measured on real Word output. Confirmed against that real Word PDF in `verification.md`. |
| UnderlineIsNotAStrike | covered | `server/test/pdf.test.ts` — "UnderlineIsNotAStrike and PageRulesAndBordersAreNotStrikes: decoys mark nothing" asserts the underlined text is returned and `doesNotMatch(/~~/)` over the whole page. `markStruckPieces` — "leaves the piece alone when the shape is an underline" pins the discriminator itself at −0.1 em. |
| PageRulesAndBordersAreNotStrikes | covered | `server/test/pdf.test.ts` — same decoy test: the fixture carries a stroked full-width page rule, a thin filled rectangle 0.8 em above a line, and a two-row table drawn with ruling lines — verticals crossing the text's own band, horizontals in the row padding, plus an outer rule drawn filled rather than stroked — and the page comes back with no markers at all. `markStruckPieces` — "leaves the piece alone for a rule far above it, or a stroked line, or a thick bar" covers each rejection reason separately, so removing any one of the three filters fails. `collectShapes` — "says which shapes were filled and which were only stroked" pins the fill/stroke reading the last of those depends on. |
| PartiallyStruckLine | covered | `server/test/pdf.test.ts` — "PartiallyStruckLine: the markers cover the struck words, not the line" asserts `~~aaaa bbbb~~ cccc dddd` where the producer emitted the line as one string. `markStruckPieces` covers the harder shapes of the same contract: "splits a piece the strike covers only part of", "marks two strikes on one piece separately, not the live words between them", and "does not read two rectangles over the same words as covering it twice" — the last two are the cases where a single covered envelope, or summed widths, would strike text the page never drew over. `wordBoundaryNear` — "snaps to the nearest edge of a word, never into one" pins the rounding. |
| StruckTextInsideAReconstructedTable | covered | `server/test/pdf.test.ts` — "StruckTextInsideAReconstructedTable: the cell keeps its span and the row its columns" asserts `\| ~~South~~ \| 900 \| 36500 \|` and then asserts every row still splits into three columns. |
| NothingIsLostToDetection | covered | `server/test/pdf.test.ts` — "NothingIsLostToDetection: stripping the markers gives the page back whole" removes every `~~` from the output and asserts both lines read exactly as they would with no detection at all, so any detection that dropped or reordered text fails. `markStruckPieces` — "keeps the whitespace inside a piece it splits" asserts the stronger form: a run of spaces inside a split piece survives verbatim, so `old   current` comes back as `~~old~~   current` and not with its spacing collapsed. |
| UnreadableDrawingOperations | covered | `server/test/pdf.test.ts` — "UnreadableDrawingOperations: a page whose drawing cannot be read loses no text" drives `pageShapes` with a page whose `getOperatorList()` rejects and asserts it returns no shapes rather than throwing. A fixture cannot produce this state, which is why it is tested at that seam. |
| DetectionStaysWithinTheBudget | covered | `server/test/pdf.test.ts` — "DetectionStaysWithinTheBudget: a drawing read that outruns the budget still fails" drives `pageShapes` with an operator list that never resolves and a 1 ms budget, and asserts a `PdfError` with reason `budget` — i.e. the swallow-and-continue path above must not swallow this one. The pre-existing "a parse that outruns its budget fails instead of hanging" still covers the whole-extraction case. |
