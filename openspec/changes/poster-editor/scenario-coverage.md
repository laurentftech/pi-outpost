# Scenario coverage — poster-editor

Every `#### Scenario:` of the change's five specs (`rg '^#### Scenario:' openspec/changes/poster-editor`, 46 in all), the test that would fail if its contract broke, and what that test asserts. Browser tests run on Chromium; the page picture was also compared in WebKit (`scripts/probes/poster-picture-webkit.mts`, task 1.3).
