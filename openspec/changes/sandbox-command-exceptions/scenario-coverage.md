# Scenario coverage

Inventory: `rg '^#### Scenario:' openspec/changes/sandbox-command-exceptions/` lists every scenario of the change, all of them below. Hosts are asked about by a command's own proxy on connection (`egressProxy.test.ts`, `confinedBash.test.ts`, and under the real executor `confinedNetworkMxc.test.ts`). Directories are asked for through `run_with_grant`, driven by the real server and agent (`sandboxGrantsServer.test.mjs`, a scripted provider and a client answering) and launched under the real runners (`sandboxGrantsReal.test.ts`; MXC on Windows run on Windows 11 for this change). The whole flow ran in the running app with a real model and no hint in the prompts (tasks 7.1, 7.2, 8.7).

## Interface checks

The UI rows above use `ui/src/components/SandboxGrantDialog.test.tsx`. For a directory request it checks: the command verbatim, every target with its access, the reason as the agent's words, the note when writing is off, each button sending one answer even on repeated clicks, no default focus, and the backdrop answering nothing. For a connection request: the heading naming the host, "The running command", "The agent did not ask for it", and "Allow for this command". `ui/src/useAgent.test.ts` covers a request held until the server resolves it, deduplicated, and the session's grants followed.
