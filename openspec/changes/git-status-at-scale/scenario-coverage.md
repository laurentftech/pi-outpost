# Scenario coverage

Scenario inventory: `rg '^#### Scenario:' openspec/changes/git-status-at-scale/`. The three
scenarios carried over from `WorkingTreeStatus` are listed with the tests that still hold them
under the new listing and the versioned answers.

| Scenario | Status | Evidence |
| --- | --- | --- |
| StatusReported | covered | `server/test/git.test.ts`, "gitStatus reports branch and tracked files", "gitStatus detects untracked files", "gitStatus detects modified files": a real repository, read with `--untracked-files=normal` plus the bounded listing, still reports the branch, a loose untracked file and a modified one with their states. |
| StatusSpansRepositories | covered | `server/test/git-multi-repo.test.mjs`, "reports both repositories, each with its own branch" and "badges files from both, keyed from the browser root": over the socket, both repositories' branches and files keyed from the browser root. |
| StatusRefresh | covered | `ui/src/useAgent.test.ts`, "StatusRefresh: a burst of changes while a status is asked becomes one trailing request, and its answer is shown": three `agent_end` while a request is out send one request; its answer moves the badge state and the branch, and one trailing request follows. "asks only the changed file's repository for a fresh status" covers `file_changed`. |
| AHugeUntrackedDirectoryIsOneEntry | covered | `server/test/git.test.ts`, "AHugeUntrackedDirectoryIsOneEntry: a large untracked directory is one entry, a small one is listed": 2,500 files under `cache/` come back as exactly one `{ path: "cache", atLeast: 2000 }` entry and nothing under it; three files in nested folders of `fresh/` come back one by one. "an untracked directory at exactly the limit is still listed file by file" pins the boundary and that ignored files are neither listed nor counted. |
| ARefreshSendsOnlyWhatChanged | covered | Server: `server/test/git-multi-repo.test.mjs`, "ARefreshSendsOnlyWhatChanged: one more modified file is the whole answer": with 300 untracked files held, the answer naming the version carries exactly the one modified file and no removal, and the state rebuilt by the protocol's rules holds all 301; a scoped refresh with nothing new carries nothing. Client: `ui/src/useAgent.test.ts`, same name: the next request names the version held, and a change answer adds one file to the 51 held, keeping the collapsed directory. |
| AFileNoLongerChangedLeaves | covered | Server: `server/test/git-multi-repo.test.mjs`, "AFileNoLongerChangedLeaves: a restored file is named as removed": the restored file is the whole `removed` list and leaves the rebuilt state. Client: `ui/src/useAgent.test.ts`, "AFileNoLongerChangedLeaves: a removed path loses its badge, and a collapsed directory its count". |
| AStrangerVersionGetsEverything | covered | `server/test/git-multi-repo.test.mjs`, "AStrangerVersionGetsEverything: a version this connection was not last sent gets the full status": a stale version on a scoped request gets a full, unscoped answer of all 300 entries with a newer version; another connection naming this one's version gets the full status too. |
| ChangesAgainstAnotherVersionAreDropped | covered | `ui/src/useAgent.test.ts`, "ChangesAgainstAnotherVersionAreDropped: keeps its state and asks again in full": a change answer based on version 2 while 3 is held leaves the state object identical, and the request sent next names no version and no repository. |
| TheBadgeSaysAtLeast | covered | `ui/src/components/FileTree.test.tsx`, "TheBadgeSaysAtLeast: a directory holding at least N untracked files shows N+, open or not, and so do its parents": `vendor` shows `2000+` closed and open, its parent `src` adds its other change as `2001+`, and the rows inside `vendor` have no diff badge while `readme.md` has one. `server/test/outcome.test.ts`, "TheBadgeSaysAtLeast: a collapsed directory is one entry with its count and no diff to open". |
